# Build Spec

## Narrativa fuente
SDD-IAgentica/specs/narrative-spec.md

## Formato esperado
- pptx editable
- 9 slides
- render completo
- review posterior

## Sistema visual
- tono visual: ejecutivo, tecnico, editorial; sobrio pero no frio
- densidad: media, con un objeto visual dominante por slide
- paleta: base del repo con fondo claro `#F4F0E8`, tinta `#0F172A`, azul profundo `#102A43`, acento naranja `#C75C2A`, verde `#2D6A4F`
- uso de tablas: solo en slide 7 para tradeoff operativo
- uso de charts: diagramas conceptuales, flows y comparaciones; no charts numericos inventados
- uso de imagenes: una imagen editorial fuerte en la slide final
- tratamiento de cierre: fondo oscuro o imagen full-bleed con overlay legible para mensaje final y cita

## Restricciones
- no romper la tesis por slide
- no meter bullets innecesarios
- no perder legibilidad
- preservar tildes y texto correcto
- mantener fuente visible cuando aplique
- incluir benchmark propio si se etiqueta como estimacion reproducible
- no usar cifras de ahorro ni precios actuales sin medicion/fuente

## Referencias visuales
- STYLE-CHARLAS.md del repo
- familia visual: cover oscuro, slides claras con barra superior corta, paneles marfil y acento naranja

## Evidencia obligatoria de build
- ruta del pptx
- cantidad de slides
- renders individuales
- chequeo textual
- chequeos mecanicos
- estado de render nativo
- riesgos residuales
