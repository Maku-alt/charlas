# Source Manifest

## Fuentes ingeridas

### `AGENTS.md`

- tipo: reglas del repo
- uso principal: workflow, roles, patron narrativo, regla de cierre
- estabilidad: alta

### `MEMORY.md`

- tipo: memoria operativa
- uso principal: estado del sistema, charlas existentes, aprendizajes previos
- estabilidad: media

### `IDEAS.md`

- tipo: backlog
- uso principal: ideas pendientes y criterios de priorizacion
- estabilidad: media-alta

### `README.md`

- tipo: descripcion general del repo
- uso principal: contexto externo del repositorio
- estabilidad: alta

### `STYLE-CHARLAS.md`

- tipo: sistema visual y narrativo
- uso principal: identidad editorial compartida
- estabilidad: alta

### `Harness Engineer/README.md`

- tipo: ficha de charla
- uso principal: ejemplo de charla madura ya compilable
- estabilidad: media

## Decision de ingest

Para un primer pase, no se ingieren todos los archivos del repo.

Se priorizan los que explican:

- reglas persistentes
- memoria estable
- backlog
- una charla ya madura

Esto ilustra una regla central de la wiki:

`no todo markdown merece entrar en el primer compile`
