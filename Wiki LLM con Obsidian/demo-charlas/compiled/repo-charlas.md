# Repo Charlas

## Resumen ejecutivo

`charlas` es un repo de presentaciones tecnicas para Data Scientists. No es solo un contenedor de PPTs: tiene reglas editoriales, memoria operativa y un flujo especializado de agentes para research, construccion de deck, cierre visual y review.

## Hechos verificados

- cada carpeta de primer nivel representa una charla
- la audiencia por defecto es `Data Scientists`
- el tono esperado es ejecutivo tecnico
- el repo ya usa `AGENTS.md`, `MEMORY.md`, `STYLE-CHARLAS.md` y `agents/`
- existe un flujo recomendado: research, deck, imagen final y review

## Interpretacion

Este repo ya se comporta como un sistema con memoria, aunque esa memoria aun no esta compilada como wiki.

Eso lo vuelve un buen candidato para `LLM Wiki` por tres razones:

1. tiene documentos con semantica distinta
2. necesita continuidad entre sesiones
3. produce preguntas recurrentes sobre prioridades, estado y narrativa
