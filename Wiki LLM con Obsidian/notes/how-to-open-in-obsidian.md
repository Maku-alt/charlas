# How To Open In Obsidian

## Objetivo

Ver `demo-charlas` como un vault real de Obsidian para inspeccionar:

- archivos markdown
- enlaces `[[wikilinks]]`
- graph view
- propiedades

## Carpeta a abrir

Usa esta carpeta como vault:

`C:\Users\Victor\Proyectos\2026\charlas\Wiki LLM con Obsidian\demo-charlas`

## Pasos

1. instalar Obsidian si aun no esta instalado
2. abrir Obsidian
3. elegir `Open folder as vault`
4. seleccionar `demo-charlas`
5. abrir `compiled/index.md`
6. navegar por los `[[wikilinks]]`
7. abrir `Graph View`

## Configuracion incluida

El vault ya trae una carpeta `.obsidian/` minima con:

- apertura inicial en `compiled/index.md`
- `Graph View` visible en el panel derecho
- parametros basicos de grafo para que la red se lea mejor

## Que deberias ver

- `index.md` como puerta de entrada
- relaciones entre:
  - `repo-charlas`
  - `flujo-de-charlas`
  - `portafolio-de-charlas`
  - `ideas-pendientes`
  - `harness-engineer`
  - `queries/que-charla-priorizar-despues`

## Limite actual

No deje una carpeta `.obsidian/` customizada porque el objetivo era demostrar la estructura de memoria compilada, no forzar una configuracion concreta de UI.

Si quieres, en la siguiente pasada puedo dejar:

- vault mas grande
- `.obsidian/` mas rica
- paginas adicionales para que el grafo se vea mas rico visualmente
