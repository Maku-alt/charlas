# Evolucion del Stack Clasico de Data Science

Esta charla explora como ha evolucionado el stack clasico de Data Science en Python a partir de un entorno realista y ampliamente usado en equipos de modelado.

## Idea central

Las librerias de siempre no se han quedado quietas. Mientras muchas organizaciones siguen operando sobre `Python 3.10`, varias bibliotecas clave del stack clasico han seguido avanzando en rendimiento, APIs, compatibilidad, explainability, soporte para nuevos backends y, en algunos casos, integracion con flujos cercanos al mundo LLM.

La pregunta de la charla no es solo "que salio nuevo", sino:

- que mejoras podemos adoptar hoy sin salir de `Python 3.10`
- que cambios relevantes exigen migrar a `Python 3.11+`
- que partes del stack realmente merecen atencion y cuales son solo ruido

## Audiencia

Data scientists y equipos tecnicos que trabajan con datos, features, modelado, optimizacion y explicabilidad en Python.

## Enfoque

La charla debe priorizar:

- decisiones practicas de upgrade
- compatibilidad real con el entorno actual
- impacto tecnico en pipelines y notebooks existentes
- comparacion entre valor entregado y costo de migracion

## Estructura sugerida

1. El stack clasico sigue vivo
2. Baseline actual del equipo
3. Hasta donde podemos evolucionar en Python 3.10
4. Que queda bloqueado hasta Python 3.11+
5. Librerias que si traen mejoras de valor
6. Recomendaciones de adopcion por prioridad
