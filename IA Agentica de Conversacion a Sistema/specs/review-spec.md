# Review Spec

## Artefacto a revisar

- `IA-Agentica-De-Conversacion-A-Sistema.pptx`
- `review/feedback-renders/Diapositiva1.PNG` a `Diapositiva10.PNG`
- `review/feedback-renders/contact-sheet-native-feedback.png`
- `review/extracted-text-feedback-pass.txt`
- `review/build-report.md`

## Criterios especificos

- La tesis debe leerse como transicion de conversacion aislada a sistema de trabajo, no como comparacion de proveedores.
- IA web debe aparecer como punto de partida valido, no como enemigo.
- La estructura minima debe presentarse como responsabilidades compartidas, no como estandar rigido de carpetas.
- Seguridad debe sentirse operativa: permisos, sandbox, scopes, datos sensibles, approvals, logs y revision.
- El caso conductor de analisis hacia features debe entenderse sin demo tecnica.
- El cierre debe sostener el mensaje: `La IA no reemplaza el sistema de trabajo. Lo exige.`
- La cita de Anthropic debe tener autor y fuente visible.
- No debe haber mojibake, caracteres sustituidos, texto cortado ni solapamientos.
- La imagen final debe reforzar la metafora de sistema de trabajo y no competir con el texto.

## Gates obligatorios

- Confirmar 10 slides.
- Confirmar que el PPTX valida y abre.
- Confirmar render nativo de PowerPoint disponible.
- Revisar contact sheet para ritmo global.
- Inspeccionar slides 7 y 9 con especial cuidado porque tuvieron fixes de build.
- Verificar texto extraido para tildes y caracteres especiales.

## Decision esperada

- `aprobado` si no hay P1/P2.
- `requiere cambios` si hay mojibake, overflow, imagen final rota, fuente ausente o solapamientos visibles.
