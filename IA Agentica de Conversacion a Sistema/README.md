# IA Agentica: de conversacion a sistema

## Titulo completo

`IA Agentica: de conversacion a sistema`

## Subtitulo

`Estructura minima, contexto, seguridad y estado para trabajar con IA agentica`

## Idea central

El salto no es usar mas IA, sino pasar de usar IA como conversacion aislada a integrarla en una estructura propia de trabajo, gobernada y segura.

## Tesis

Pasar de IA en la web a IA agentica no es solo cambiar de interfaz. Es mover la IA dentro de una estructura de trabajo donde existen reglas, contexto, estado, permisos, outputs verificables y revision humana.

## Audiencia

Audiencia mixta: analistas que ya usan IA web y Data Scientists que trabajan con repos, scripts, notebooks, datos y flujos de modelamiento.

## Pregunta que responde la charla

Como pasamos de conversaciones utiles pero aisladas a una forma de trabajo con IA agentica que sea trazable, adaptable y segura para el equipo.

## Estructura de la charla

1. La escena actual: usamos IA web para acelerar trabajo, pero el contexto queda disperso.
2. El limite del chat aislado: poca trazabilidad de datos, decisiones, restricciones y pendientes.
3. El cambio mental: de preguntar a la IA a disenar un entorno donde la IA trabaja con nosotros.
4. Que significa sistema: estructura minima con reglas, contexto, estado, outputs y controles.
5. Blueprint minimo: responsabilidades obligatorias antes que carpetas obligatorias.
6. Una estructura posible: `AGENTS.md`, `MEMORY.md`, `skills/`, `cases/<caso>/state.md`, `notes/`, `outputs/`, `review/`.
7. Caso conductor: un analisis de negocio que evoluciona hacia preparacion de features.
8. Seguridad corporativa: skills confiables, sandbox, permisos controlados, scopes pequenos y no leer datos sensibles innecesarios.
9. Que cambia para el equipo: libertad de adaptar la estructura sin perder trazabilidad, revision ni seguridad.
10. Cierre abierto: que minimo comun necesitamos como equipo.

## Cierre aprobado

Mensaje principal:

> La IA no reemplaza el sistema de trabajo. Lo exige.

La cita de Anthropic se uso como fuente de apoyo durante research y specs, pero el deck final cierra con frase editorial propia.
